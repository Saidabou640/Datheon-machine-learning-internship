### Task 1: Multi-Class Benchmark Classification Pipeline

**Status:** Completed

- Dataset: Iris
- Task: Supervised multi-class classification
- Models:

  - Decision Tree
- Techniques:
  - Data preprocessing
  - Exploratory Data Analysis (EDA)
